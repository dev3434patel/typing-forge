## What changed

The input path avoids repeated passage allocation when there are no extra characters, avoids temporary flattened keyboard arrays, and caches the session's current text by event sequence with invalidation before edit application. The transcript shortcut mutates only newly created character slots backed by a private immutable-target contract; external/sparse/proxy-like arrays keep the original behavior. The source and regression checks preserve scoring, correction, Unicode and partial-error semantics.

Physical key feedback updates its owned DOM attribute directly rather than rerendering the keyboard on every press. Cleanup releases that attribute, rejects old copied callbacks and repairs store/static ownership after commits. Held-key borders keep their geometry. The **2D** key and caret response durations are 55 ms. The 3D scene, geometry, shaders, lighting and worker quality are preserved. The full matrix currently exposes assertion mismatches in related keyboard tests; this draft does not conceal them as a performance success.

Race feedback now tracks checkpoint, finish and local-save requests separately. A newer successful checkpoint clears its own stale checkpoint error. A client's acknowledged final submit supersedes checkpoint feedback; a late checkpoint rejection cannot resurrect an obsolete finish alert. Genuine current final-submit failures retain Retry finish, and device-save failures remain independent. Server room polling alone cannot confirm this client's finish. [Implementation and preparation](../2026-10-27/final27-race-recovery-preparation.json), [independent source review](../2026-10-27/final27-race-feedback-keycap-independent-review.json).

The backend admits recognized authenticated Arena requests through the existing per-account 300/minute allowance after checking the live account and authentication version. Anonymous/general IP and authentication policies remain. Atomic counter increments return each caller's own count. Full candidate prevalidation runs before room/account locks; the DB receipt precedes preparation, while the locked stage still checks current membership, issuance, prefix, status, start, elapsed/event allowance, staleness and finish grace. The independent authoritative-elapsed replay remains. [Capacity/architecture ledger](../../docs/ARENA_CAPACITY_2026-10-27.md).

The JSON request parser performs one associative decode on ordinary objects and preserves the exact old decoder path for a raw `\u0000` escape. That fallback preserves rejection even when a duplicate property would otherwise discard an invalid NUL-key subtree. Numeric-key objects, whitespace, UTF-8/depth/error precedence and size/CSRF checks retain their contract. On the identical representative fixture, the [pure diagnostic](../2026-10-27/request-body-production-diagnostic-result.json) measured median parse **6.18030→2.95435 ms** and **3,073,080 bytes** less retained/peak memory. Those isolated samples do not prove an exclusive HTTP speedup.

Arena uploads omit only `characters`, `timeSeries` and `cursor`, which the server reconstructs before canonical hashing. Raw events, targets, configuration, pauses, metrics, owner and privacy fields remain. Full local/exported evidence stays intact. The paired corpus verifies exact accepted bytes/hash/projections and matching rejection behavior. The [identity proof](../2026-10-27/final27-backend-wire-evidence-inheritance.json) shows six changed existing source files and 499 unchanged between source26 and source27, including all 38 protected backend files and both Arena wire modules. Backend results are inherited only within that exact scope; source26 frontend results are not reused for source27.
