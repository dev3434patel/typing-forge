# Arcade originals

The editorial word pool, eight game descriptions/tutorials, procedural Canvas art, CSS catalog illustrations and oscillator motifs in this directory were authored for SparowType on2026-10-21. No competitor code, logo, sprite sheet, audio recording or scraped passage is included.

Individual common English words are used as typing targets; the ordered collection and game passages are an original editorial selection. Daily passages are generated from that collection. Ghost mode may use an explicitly selected replay belonging to the current owner; private custom passages are excluded from its picker.

Web platform documentation informs browser API use; it supplies no bundled game assets. Runtime and library dependencies remain governed by the repository's existing dependency licences.
