# Typing Forge v2 roadmap

Prompt 0 rules apply to every phase: one metrics engine, no `any`, tests for every change, no production `console.log`, loops are capped.

| Phase | Prompt | Outcome | Status |
| --- | --- | --- | --- |
| Foundation | 1 | Keystroke accuracy, bot loop caps, lint 0, CI | Done |
| Typing feel | 2 | Focusable input, caret, IME, keystroke-to-paint budget | Not started |
| Design system | 3 | Token themes, contrast tests | Not started |
| Mobile + PWA | 4 | Drawer, bottom bar, offline | Not started |
| Test modes | 5 | MonkeyType-parity options, command palette | Not started |
| Adaptive | 6 | Keybr-style letter unlocking | Not started |
| Lessons | 7 | TypingClub-style course and on-screen keyboard | Not started |
| Analytics | 8 | Results and history at scale | Not started |
| Race | 9 | Realtime, fair bots, no hangs | Not started |
| Security | 10 | RLS, server-side scoring, anti-cheat | Not started |
| Retention | 11 | XP, streaks, daily text | Not started |
| Performance | 12 | ≤ 120 KB initial JS, Lighthouse | Not started |
| A11y + i18n | 13 | WCAG 2.2 AA, UI languages | Not started |
| Quality gates | 14 | Coverage thresholds, Playwright | Not started |
| Re-audit | 15 | Evidence-backed canvas, no code changes | Not started |

Do not start the next phase until the current definition of done passes.
