# Placement and free practice

This extension reuses the canonical `SessionController`, current live keyboard/finger tables and the existing English/QWERTY course. It does not change `typing-course-v1`, its 108 original passages, two-variant checkpoints, numerical qualification rules, PHP validator or comparison policy.

The optional placement has three original 45-second passages, 135 seconds total. `placementV1` is a new local guidance metric: median canonical headline WPM across the three parts and insertion-attempt-weighted accuracy. Each part requires 25 individual keyboard attempts, a complete uninterrupted 45-second timeout and the known passage. All three parts must share one explicit run ID. Skipping, leaving and retaking are allowed. Mixed retakes, another owner, composed/bulk input and early finishes do not create a placement measurement. A suggested lesson does not unlock or certify it. Each completed part also offers the same canonical key, reference-finger and latency diagnostics used by ordinary results.

Each qualifying part stores a small `placementEvidence` projection alongside the existing result: owner/session/run IDs, stage, version, duration, canonical WPM and attempt counts. It contains no passage or keystroke transcript. Validation checks identity, metric version, method, layout, count arithmetic and numerical bounds before using retained facts. Raw replay wins while present. The projection survives 90-day replay expiry; deleting its session or owner removes it with that record. It is local guidance rather than server certification. No SQL migration is required for placement or the established course.

Practice assist is available for every selected skill, including a currently locked lesson. It uses a separate `private-custom` canonical session without course metadata, with review set explicitly. There is no pace deadline in assist. It cannot award course checkpoints/stars, unlock adaptive mastery or become a ranked result. The fixed course remains available through its existing start button. Finger hints reference the selected physical layout; the application cannot sense which finger a person used.

The studio offers home-row patterns, seeded phonetic drills, original vocabulary, original sentence rhythm, code symbols, numbers/symbols and focused keys. Its small lexicon and Markov transitions are authored here; no competitor source, downloaded dictionary, runtime network service or external text asset is used. Generation is reproducible by version/seed and never emits a key outside its supplied alphabet, apart from word separators. Weak-key weighting is capped at 4×. Introduced-alphabet controls cap the available practice letters without introducing a locked letter into the mastery model.

The English adaptive lesson generator now uses these original Markov drills for at least one in five word items, falling back to them whenever a restricted alphabet lacks a natural word. Every new-key word retains its selected focus. Its version is `forge-markov-v4`; other language packs retain `forge-pattern-v3`. Existing saved target text replays unchanged, and generator versions keep the new comparison cohorts separate. A CC0 Markov vocabulary for every other shipped language has not been supplied or verified; the English original vocabulary must not be described as such a dataset.

The practice studio lazily reads the current owner's exact English/layout/keyboard/prose Progression SkillMap. Its problem exercise takes at most five keys or bigrams with at least 20 observations and Bayesian accuracy below 92%, preserves a selected weak pair together, and weights individual weak keys. If that scope has no map, the existing scoped adaptive statistics remain the measured fallback. Other owners, layouts, languages and input methods are never pooled. Spaced review also reads the selected scope.

Planning confidence is a separately labeled hint: `min(1, targetMs / smoothedMs) × smoothedAccuracy`. A pure next-key suggestion requires 20 samples for every active key and the selected confidence threshold. It does not replace actual mastery. The studio explains the existing assessment contract and displays actual assessment states/checkpoints: at least 20 attributable attempts over two dedicated lessons, at least 97% accuracy at target pace, two consecutive qualifying checkpoints, and mastery of every introduced key before another is introduced.

Spaced-review guidance uses 1, 3, 7 calendar-day intervals and deduplicated session/key observations. A weak revisit resets to one day. Free key/word drills interleave due supported keys at no more than 30% of generated word items; sentence/code exercises retain their structure. This is an original lightweight scheduler, not an efficacy claim or a full SM-2 implementation. Review remains isolated by owner, language, layout, domain and input method; the dashboard visibly labels its current English/QWERTY keyboard-prose scope. Expired raw evidence is not recreated for key review.

Private assist adds the named `training-goal-v1` feedback rule: complete the target, reach at least 90% insertion accuracy, and meet 105% of the median WPM from the last five completed comparable attempts. With no prior evidence it uses a comfortable stage target. Owner, exercise type/alphabet, generator/content revision, language, layout, method, scoring policy and correction policy stay separate. Speeds are replayed rather than taken from mutable summaries; duplicate, future, incomplete and foreign-owner attempts are excluded. These practice goals and their 1/2/3 stars at 90/95/98% are local feedback recomputable while raw evidence remains, not new course authority. Two failed course attempts explicitly offer untimed assist with a larger finger reference; assist is already freely available before a failure.

Course stars are recomputed from the existing validated assessment: 1 for a qualifying attempt, 2 at 95% input accuracy, 3 at 98% plus the course speed check. Accepted server assessment takes precedence, including failure; otherwise canonical replay is used, then the existing validated retained course summary. Course stars survive normal replay expiry through that bounded validated summary. Both sets of stars are personal feedback and never an identity-verified certificate. The fixed course gates deliberately remain separate from the rolling private-practice goal.

Focused unit checks cover deterministic generation, locked alphabets, weight bounds, review caps/date edges, supported finger maps, assist isolation, placement run isolation, retained summaries, owner boundaries and assessment precedence. Browser, physical-device, hosted deployment and learning-effect validation remain separate gates; they are not established by unit tests. The new `learning-analytics-v2.spec.ts` is prepared for the parent-coordinated browser matrix.
