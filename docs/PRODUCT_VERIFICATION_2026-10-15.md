# Typing Forge product verification ledger

Audit started **15 October 2026**; follow-up recorded **16 October 2026, Asia/Calcutta**. This ledger separates implemented behavior, executable local checks and deployment/native-device work that remains unverified. It records a finite test surface; it does not claim that every possible browser, event ordering, keyboard or user action has been proved correct.

The user's supplied result has consistent input/final accuracy arithmetic. Formula semantics and differences from current Monkeytype/Keybr source are documented in [the competitor and accuracy research](./COMPETITOR_ACCURACY_RESEARCH_2026-10-15.md). The [accuracy upgrade report](./ACCURACY_UPGRADE_2026-10-15.md) describes the implemented follow-up and supersedes earlier feature/count statements where they differ. This ledger covers the implementation's behavior and trust boundaries instead of inferring accuracy from appearance.

## Defects reproduced and repaired in this audit

1. **Deletion could act on a different current account than the UI's intended owner.** Five client regressions demonstrated missing expected-owner/token binding and late-response guards. Requests now carry owner intent and a captured bearer. SQL and Edge enforce the owner instead of relying on the browser UI alone.
2. **Quick match could return the owner's waiting room for a different duration.** The reuse query lacked the requested-duration predicate. The new fixture requests 30 seconds, then 60, then 30 and checks distinct/matching room IDs; another owner joins the 60-second room. The additive migration repairs this query.
3. **History could retain previous-account rows during the first render after switching owners.** The React state now carries its owner. Mismatched state returns an empty loading view immediately; it cannot feed Profile/Stats/Settings export with the old account's records. Repository records are preserved for later return to that owner.
4. **An unsaved private passage could remain visible after switching accounts.** Owner-scoped persistent history did not reset component state in the current route. `AccountWorkspace` now remounts routed children when the owner changes, intentionally discarding unsaved passages, active sessions and transient results. The intercepted cross-tab regression failed before the guard and passed in all three engines in the completed matrix; fixture identities never reached a real cloud service.
5. **Holding the command shortcut could toggle/reopen the palette through repeated keydown events.** The repeat regression failed against the archived earlier static build. One root listener now controls palette state instead of handing shortcut ownership between components; repeat and composition events do not toggle it. The command-repeat/navigation case passed in Chromium, Firefox and WebKit after the fix. Separate WebKit dialog stress stalls and a Firefox context-teardown failure remain unresolved verification gates.

The combined follow-up also repaired target-issuance replay ordering, early timeout claims, Unicode edit-boundary reconciliation, qualified per-key timing consistency and malformed lifecycle metadata, with the 431-test conformance checkpoint above. It added public passage identity/private comparison isolation, canonical word-credit trace and recorded-edit playback. See [metric conformance](./METRIC_CONFORMANCE_2026-10-15.md) and [the accuracy upgrade report](./ACCURACY_UPGRADE_2026-10-15.md) for exact contracts and finite evidence. AccountWorkspace's intercepted-auth regression is explicitly separate from real hosted account verification.

## Release gates that remain

- Deploy all 15 migrations and three Edge functions together to a disposable/staging Supabase environment. Refresh generated database types. Install scheduled jobs and inspect actual job runs.
- Run real authenticated two-/three-client room and ranking flows, packet loss/retry, simultaneous joins/finishes, deletion/upload concurrency, account switching, direct REST/RPC attacks and account-deletion cascades.
- Resolve the remaining WebKit dialog/loading stress failures and Firefox context-teardown/tracing failure. Retain both the traced Firefox failure and the successful single-case trace-disabled comparator; normal configuration still retains traces. The current Chromium suite passed its 50 applicable cases, but a readiness wait and three passing command-repeat cases do not establish an all-engine release pass. Report credential-gated skips honestly. Composition events cover adapter behavior, not physical IME operation.
- Exercise Windows/macOS/Linux native input methods, mobile keyboards, assistive technology and intended browser engines. Validate non-Latin font fallback, RTL caret/scroll behavior and copy/export rendering on those systems.
- Measure field performance after deployment; a local bundle budget is not evidence of actual-user LCP/INP/CLS. Long-term learning improvement requires a user study with matched unseen-content assessments.

Source code, arithmetic and a passing local test suite can establish specific invariants. They cannot establish universal hardware detection, error-free behavior for all future inputs, worldwide product rank or mathematical certainty about a user's learning outcomes.
