## What changed

Source32 changes Learn's empty native draft path. A trusted, cancelable ordinary insertion can enter the existing commit path before the browser inserts and React clears a temporary native character. The guard preserves the native path for composition, replacement edits, noncancelable or synthetic input, a nonempty draft and line-break data. Deletion and empty-space correction run first. The same composition-ownership and commit routines serve both paths; no fabricated native input event or elapsed-time override was introduced. Main test/race input, metric formulas and server replay were not changed by this step.

The browser contracts use actual native behavior. A [standalone four-engine diagnostic](../audit/2026-11-02/source32-native-browser-semantics-result.json) showed differences in synthetic composition type handling, Firefox insertion through composition and WebKit command-level CRLF behavior. The [test-correction receipt](../audit/2026-11-02/source32-learning-test-correction.json) binds the supported echo type and same-browser native reference while retaining exact text and attempt counts. The earlier [83-pass/9-fail run](../audit/2026-11-02/final32-learning-candidate-integrity-qualification.json) remains invalid for acceptance because a test assertion changed after it began; the separate92-case confirmation has stable hashes. [MDN's beforeinput guidance](https://developer.mozilla.org/en-US/docs/Web/API/Element/beforeinput_event) explains why the native input fallback is necessary when edits do not deliver a cancelable event.

Source33 changed only two PHP files. The default replay path still builds charts. A non-finish Arena checkpoint explicitly omits chart generation from the **independent authoritative replay** because that interim branch consumes its metrics and retained text; finished results still build their chart. Independent event replay, metrics/rhythm, server elapsed time, membership, immutable prefixes, issuance, current status, grace and locks remain the required boundaries. Its578 projection and19 rejection contracts passed; its actual native and failed capacity results remain separately recorded above.

Source34 changes the three PHP files named in the current identity row. Its dedicated checkpoint projection retains full candidate validation/replay, all canonical candidate fields and candidate chart, course assessment, and unsorted JSON-encoding validation with the same flags/depth. Only Arena's non-finish branch opts into omitting unused persistence bundle/hash derivation. An explicit checkpoint-only marker makes `DataService` reject such a bundle before database work; the normal full/final result path remains unchanged. The [adoption receipt](../audit/2026-11-04/source34-checkpoint-adoption.json), fresh578-row differential corpus and eight actual nonfinite-JSON rejection pairs constrain this change. They do not substitute for fresh native and load measurements. The frontend reuse is limited to unchanged bytes and the specifically bound source33 measurement receipts, with no source34 runtime pass implied.

The [first private chart-error probe](../audit/2026-11-04/source33-chart-errors-first-probe-qualification.json) is retained as failed: an out-of-contract fractional sequence reached a pre-existing PHP deprecation outside public candidate validation.
